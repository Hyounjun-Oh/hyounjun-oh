## 👋 About

I'm a robotics software engineer bringing **robot manipulators to real manufacturing sites**.
Before that, I built perception and localization software (**Visual / Visual-Inertial SLAM**, **multi-sensor calibration**,
**semantic & object mapping**), from designing the hardware to deploying the algorithms on real robots.

### 🔭 Currently
- 🏭 Applying **manipulators to manufacturing processes** at GlobalDefense
- 🧪 Building simulation environments in **NVIDIA Isaac Sim**
- 🧠 Training manipulator policies with **reinforcement learning** for sim-to-real deployment

### ✨ Highlights

- 🏆 Co-developed a multi-camera SLAM device recognized as a **CES 2026 Innovation Awards Honoree** (Construction & Industrial Tech)
- 🤖 Background in **Mechanical + Electronic Engineering**, so I'm comfortable with both CAD and C++
